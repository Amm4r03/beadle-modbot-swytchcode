## Track 1 — AI Software Engineer

**Problem Statement:** Build an AI Software Engineer that can understand development tasks, work with code repositories, track issues, and assist development teams.

**Objective:** Create an AI agent that automates coding workflows, issue management, task tracking, and developer communication.

**Integrations:** GitHub, Jira, Slack

---

## Track 2 — AI Knowledge Worker

**Problem Statement:** Build an AI Knowledge Worker that can search, understand, organize, and summarize information from different workplace tools and documents.

**Objective:** Create an AI agent that helps users find information, answer questions, summarize documents, and manage knowledge.

**Integrations:** Gmail, Google Drive, Notion, Box, Slack

---

## Track 3 — AI Community Agent

**Problem Statement:** Build an AI Community Agent that can monitor community conversations, understand member needs, and support community engagement.

**Objective:** Create an AI agent that can discover discussions, respond to queries, share updates, and automate community workflows.

**Integrations:** X, Telegram, Slack, Notion, Resend

---

## Track 4 — AI Meeting and Productivity Agent

**Problem Statement:** Build an AI agent that helps users manage meetings, capture important information, and turn conversations into actionable tasks.

**Objective:** Create an AI agent that can organize meeting information, summarize discussions, track action items, and improve productivity.

**Integrations:** Google Meet, Gmail, Notion, Google Drive, Slack

---

## Track 5 — AI Real World Agent

**Problem Statement:** Build an AI agent that can understand real-world situations using external information and take useful actions for users.

**Objective:** Create an AI agent that combines real-time information with user context to provide recommendations, send updates, and automate everyday tasks.

**Integrations:** OpenWeather, Gmail, Notion, Slack, Resend

---

## Track 6 — AI Business Operator Agent

**Problem Statement:** Build an AI Business Operator that can assist with business operations, payments, tasks, and team workflows.

**Objective:** Create an AI agent that automates operational tasks, coordinates across business tools, tracks work, and supports faster decision-making.

**Integrations:** PayPal, Gmail, Slack, Jira, Notion
